# Omar's Hackpad
A simple macropad consists of 4 switches, a rotary encoder ( with switch ), xiao rp2040, and the switches are aligned in 2x2 grid.
It uses direct pin connection.

# Dimensions
PCB Dimensions: 81.5mm x 61.00mm
Case Dimensions: 101mm x 65mm

# BOM
- 4x cherry mx 1.00u switch
- 1x seediuno xiao rp2040
- 1x rotary encoder
